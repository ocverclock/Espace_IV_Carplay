## Électronique observée

Les photos et relevés montrent :

- microcontrôleur principal NEC Japan en QFP ;
- quartz externe `X1` ;
- carte avant avec boutons `SWx`, LEDs et joystick / encodeur central ;
- protections / conditionnement autour de `CN1` ;
- filtre de mode commun TDK marqué `ZJY2401` ;
- `IC3` en SO8 marqué :

```text
A82C250
5K3A3
N5464
PHILIPS
```

Le marquage d'`IC3` correspond au **Philips/NXP PCA82C250**, transceiver CAN haute vitesse ISO 11898.

Le CSW est donc une commande électronique active reliée à un **bus CAN confirmé**.

## IC3 — PCA82C250

Pinout constructeur :

| Pin IC3 | Fonction |
|---:|---|
| 1 | TXD |
| 2 | GND |
| 3 | VCC — 5 V nominal |
| 4 | RXD |
| 5 | Vref |
| 6 | CANL |
| 7 | CANH |
| 8 | Rs — slope / standby |

Le PCA82C250 est l'interface physique entre le contrôleur CAN/MCU et le bus différentiel.

La continuité a été vérifiée jusqu'aux sorties du `PCA82C250` :

```text

PCA82C250 pin 6 = CANL → CN1-11 / CN1-12
```

```text

CN1-6 = CANH
CN1-11 = CANL
CN1-12 = CANL
```

## Prochaines mesures prioritaires

### 1 — vérifier la terminaison CAN

Carte hors tension, mesurer la résistance entre :

```text
CANH = CN1-5/6
CANL = CN1-11/12
```

Noter la valeur stabilisée :

- proche de `120 Ω` → terminaison locale très probable ;
- valeur nettement supérieure / circuit ouvert → probablement pas de terminaison locale.

Cette mesure doit être faite module seul, débranché du véhicule.

### 2 — alimentation

Le `PCA82C250 pin 3` confirme un rail interne 5 V, mais l'entrée positive côté CN1 reste inconnue.

- suivre pin 3 vers le rail 5 V ;
- identifier régulateur / protection ;
- remonter vers CN1 ;
- ne pas appliquer 12 V avant identification certaine.

### 3 — TXD / RXD

Toujours hors tension :

```text
PCA82C250 pin 1 = TXD
PCA82C250 pin 4 = RXD
```

Suivre ces pistes vers le MCU NEC.
