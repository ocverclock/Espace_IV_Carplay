## IC3 — PCA82C250

Pinout constructeur utile :

| Pin IC3 | Fonction |
|---:|---|
| 1 | TXD |
| 2 | GND |
| 3 | VCC — 5 V nominal |
| 4 | RXD |
| 5 | Vref |
| 6 | CANL |
| 7 | CANH |
| 8 | Rs — slope / standby |

Le PCA82C250 est l'interface physique entre le MCU et le bus différentiel CAN.

Plage normale de VCC : `4,5 à 5,5 V`.
Limite absolue de VCC constructeur : `9 V`.

## Alimentation — état validé sur banc

### CN1-7 → D1 → condensateur d'entrée C25

Correction de sérigraphie confirmée sur la carte : le gros électrolytique `220 µF / 25 V` est **C25**, et non C2.

Le pad d'alimentation supérieur près de C25 est en continuité avec `CN1-7`. Le pad inférieur est relié à la masse et donc à `CN1-2/8`.

Le traçage montre :

```text
CN1-7 → D1 → rail du gros condensateur C25 220 µF / 25 V
CN1-2/8 → GND → borne négative de C25
```

Mesure en mode diode sur `D1` :

```text
Vf(D1) = 0,551 V
```

Statut : **MEASURED / USER CONFIRMED — 2026-09-04**.

### C3 / PCA82C250 — rail 5 V confirmé sous tension

`C3` (`47 µF / 16 V`) est sur le rail qui alimente `PCA82C250 pin 3 = VCC`.

Premier essai exploitable sur banc :

```text
alimentation principale mesurée : 12,5 V
wake CN1-1 / 34HU : appliqué via résistance série
C3+ : 5,0 V
```

Le rail interne 5 V est donc **correctement régulé** avec une alimentation principale à `12,5 V` et le wake appliqué.

Statut : **MEASURED / USER CONFIRMED — 2026-09-04**.

Les valeurs précédemment notées `16 V` en entrée et `11,3 V` sur le second condensateur provenaient d'une **erreur de mesure** et sont invalidées.

### Q1 / IC1 — fonction globale établie, topologie interne encore TBD

Le chemin détaillé entre `C25` et `C3` implique l'étage `Q1 / IC1`, dont le brochage exact reste à cartographier. En revanche, le fonctionnement global est désormais établi : cet étage fournit bien le rail 5 V lorsque le module est alimenté et réveillé.

```text
CN1-7 = BCP4 + batterie protégé
  │
  ▼
 D1
  │
  ▼
C25 220 µF / 25 V
  │
  ▼
étage Q1 / IC1
  │             ▲
  │             │
  │        CN1-1 = 34HU
  │        réveil multimédia
  ▼
C3 47 µF / 16 V
  │
  └──► 5,0 V → PCA82C250 pin 3
```

Le rôle fonctionnel du wake est **fortement corroboré**, mais pour le démontrer isolément il reste utile de mesurer `C3` avec `CN1-1` déconnecté puis connecté, en maintenant `12,5 V` sur l'alimentation principale.

Le détail exact de `Q1` n'est plus bloquant pour commencer l'analyse CAN.
