## Observations PCB

### CONFIRMED / OBSERVED

Les photos montrent :

- microcontrôleur principal NEC Japan en QFP ;
- quartz externe `X1` ;
- carte avant avec boutons `SWx`, LEDs et joystick / encodeur central ;
- composants de protection / conditionnement proches de `CN1` ;
- `ZD4`, `ZD5`, `VR3` et divers transistors/passifs ;
- composant TDK marqué `ZJY2401` près de `CN1` ;
- `IC3` en boîtier 8 broches à proximité du filtre et de `VR1/VR2`.

Le CSW est donc une commande électronique active et non une simple matrice passive exposée directement au faisceau.

### Pins 6 et 12

Traçage visuel / continuité sur la carte :

```text
CN1 pin 6  → TDK ZJY2401
CN1 pin 12 → TDK ZJY2401
```

Statut : **MEASURED / USER CONFIRMED — 2026-09-04**.

Le `TDK ZJY2401` est un **filtre de mode commun 4 broches** pour une paire de lignes. Cela indique fortement que les pins `6` et `12` sont les deux conducteurs d'une même interface filtrée.

Interprétation de travail :

```text
pin 6  ─┐
        ├─ paire de lignes → filtre de mode commun ZJY2401 → électronique d'interface
pin 12 ─┘
```

Cette topologie est compatible avec un bus différentiel automobile, notamment CAN, mais **ce n'est pas encore une preuve de CAN**. TDK utilise ce type de filtre sur plusieurs interfaces de communication et sur des applications CAN.

Il faut maintenant suivre **l'autre côté du ZJY2401** et identifier le circuit auquel ses deux sorties sont reliées.

## Hypothèses protocolaires

### CAN

**Plausibilité en hausse**, car :

- deux lignes sortent ensemble par `CN1` ;
- ces deux lignes traversent un filtre de mode commun ;
- cette architecture est classique pour une paire différentielle automobile.

Mais il manque encore au moins un élément décisif :

- identification d'un transceiver CAN ; ou
- mesure électrique des deux lignes alimentées ; ou
- observation de trames CAN.

Donc statut actuel : **LIKELY DIFFERENTIAL PAIR / CAN NOT CONFIRMED**.

### UART / LIN / autre

Toujours possibles tant que le circuit d'interface n'est pas identifié.

## Prochaine mesure prioritaire — autre côté du ZJY2401

Carte **hors tension**.

Le ZJY2401 possède quatre broches : deux côté connecteur, deux côté électronique.

Objectif : déterminer où vont les deux sorties internes.

1. repérer les deux pattes du ZJY2401 qui **ne** vont pas à `CN1-6` et `CN1-12` ;
2. multimètre en continuité ;
3. suivre chacune vers `VR1`, `VR2`, `IC3` ou un autre composant ;
4. noter exactement les broches d'`IC3` atteintes si continuité directe ;
5. si les deux lignes convergent vers `IC3`, faire une photo macro parfaitement nette de son marquage.

## Alimentation — encore inconnue

Les pins `2` et `8` sont GND, mais l'entrée positive et la tension nominale ne sont pas encore établies.

Ne pas appliquer 12 V tant que le chemin d'alimentation n'est pas tracé.

Pour la suite :

- tracer la borne `+` du condensateur `220 µF / 25 V` ;
- rechercher sa liaison aux pins restantes ;
- suivre les protections/régulation ;
- alimentation de laboratoire seulement après identification certaine.

## Analyse dynamique ultérieure

Une fois alimentation et interface identifiées :

- oscilloscope / analyseur logique sur les lignes `6` et `12` côté intérieur du filtre ;
- relever tensions au repos ;
- appuyer sur boutons / joystick ;
- observer activité et structure des trames.

Selon résultat :

- CAN → transceiver + écoute passive ;
- LIN → transceiver LIN ;
- UART → analyseur logique/UART ;
- autre série → décodage maison.

## Fallback

Si le protocole Xanavi est trop coûteux à reproduire :

- conserver boîtier, boutons, LEDs et joystick ;
- bypass de l'électronique d'origine ;
- RP2040 comme nouvelle logique interne ;
- USB HID vers Raspberry Pi.

Ce fallback reste valide, mais seulement après tentative raisonnable d'identification du protocole d'origine.
