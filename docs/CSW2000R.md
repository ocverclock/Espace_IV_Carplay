## Alimentation — traçage en cours

### Nouvelle mesure : CN1-7 → D1 → condensateur d'entrée

Le pad d'alimentation supérieur près du gros condensateur est en continuité avec `CN1-7`. Le pad inférieur est relié à la masse et donc à `CN1-2/8`.

Le traçage montre maintenant :

```text
CN1-7 → D1 → rail du gros condensateur 220 µF / 25 V
CN1-2/8 → GND → borne négative du condensateur
```

Mesure en mode diode sur `D1` :

```text
Vf(D1) = 0,551 V
```

Statut : **MEASURED / USER CONFIRMED — 2026-09-04**.

Interprétation : `0,551 V` est cohérent avec une diode silicium utilisée en série dans le chemin d'alimentation, très probablement pour protection contre inversion de polarité. Cela fait de `CN1-7` un **candidat très fort pour l'entrée positive d'alimentation**, mais le sens exact anode/cathode doit encore être confirmé en notant l'orientation des pointes du multimètre et la mesure dans le sens inverse.

Ne pas encore marquer `CN1-7 = +12 V` tant que :

1. le sens de `D1` n'est pas confirmé ;
2. le rail après D1 n'est pas suivi jusqu'à l'étage de régulation ;
3. la tension nominale d'entrée n'est pas validée.

### Rails attendus connus

Le `PCA82C250 pin 3` doit recevoir un rail logique d'environ **5 V**. Le gros `220 µF / 25 V` est placé côté entrée/protection ; le petit `47 µF / 16 V` proche de `IC1` est un candidat pour un rail aval régulé, à confirmer par continuité.

### Prochaines mesures alimentation

Carte hors tension :

1. confirmer le sens de D1 : relever `0,551 V` avec orientation rouge/noire puis vérifier `OL` ou valeur inverse dans l'autre sens ;
2. mesurer continuité `+220 µF` vers les broches de `IC1` pour identifier l'entrée de régulation ;
3. mesurer continuité `+47 µF / 16 V` vers `PCA82C250 pin 3` ;
4. vérifier `-47 µF` vers GND ;
5. relever le marquage exact de `IC1` ;
6. seulement après identification de l'étage, décider de la première tension d'alimentation labo.
