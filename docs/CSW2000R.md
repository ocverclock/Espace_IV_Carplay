## Électronique observée

Les photos et relevés montrent :

- microcontrôleur principal NEC Japan en QFP ;
- quartz externe `X1` ;
- carte avant avec boutons `SWx`, LEDs et joystick / encodeur central ;
- protections / conditionnement autour de `CN1` ;
- filtre de mode commun TDK marqué `ZJY2401` ;
- `IC3` en SO8 marqué :

```text
A82C250
5K3A3
N5464
PHILIPS
```

Le marquage d'`IC3` correspond au **Philips/NXP PCA82C250**, transceiver CAN haute vitesse ISO 11898.

Le CSW est donc une commande électronique active reliée à un **bus CAN confirmé**.

## IC3 — PCA82C250

Pinout constructeur :

| Pin IC3 | Fonction |

| 4 | RXD |
| 5 | Vref |
| 6 | CANL |
| 7 | CANH |

Le PCA82C250 est l'interface physique entre le contrôleur CAN/MCU et le bus différentiel.


Ces deux nets passent par le filtre de mode commun `TDK ZJY2401`, puis rejoignent les sorties CAN du `PCA82C250`.

### 2 — vérifier la terminaison CAN

Toujours hors tension, mesurer la résistance entre les deux nets :

```text
CN1-5/6 ↔ CN1-11/12
```

Noter la valeur. Une valeur proche de `120 Ω` indiquerait une terminaison locale ; une valeur nettement plus élevée indiquerait probablement l'absence de terminaison sur ce module.

### 3 — alimentation
