## Alimentation — traçage en cours

### CN1-7 → D1 → condensateur d'entrée

Le pad d'alimentation supérieur près du gros condensateur est en continuité avec `CN1-7`. Le pad inférieur est relié à la masse et donc à `CN1-2/8`.

Le traçage montre :

```text
CN1-7 → D1 → rail du gros condensateur C2 220 µF / 25 V
CN1-2/8 → GND → borne négative de C2
```

Mesure en mode diode sur `D1` :

```text
Vf(D1) = 0,551 V
```

Statut : **MEASURED / USER CONFIRMED — 2026-09-04**.

Interprétation : valeur cohérente avec une diode silicium série de protection d'alimentation. `CN1-7` est un candidat très fort pour l'entrée positive, mais sa tension nominale côté véhicule reste à confirmer.

### IC1 / C3 — étage 5 V confirmé fonctionnellement

Nouveau traçage utilisateur :

- `IC1` alimente directement le `PCA82C250` ;
- le condensateur `C3` (`47 µF / 16 V`) est raccordé sur la **sortie de IC1** ;
- cette même sortie rejoint `PCA82C250 pin 3 = VCC`.

Le PCA82C250 nécessitant un rail nominal de 5 V, la fonction de l'étage est maintenant établie :

```text
C2 / rail après D1
      │
      ▼
     IC1
      │
      ├──► C3 47 µF / 16 V
      └──► PCA82C250 pin 3
             VCC ≈ 5 V
```

Conclusion : **IC1 est le régulateur / étage de régulation qui génère le rail logique 5 V**.

Statut : **FUNCTION CONFIRMED / EXACT PART NUMBER TBD — 2026-09-04**.

Ce qui reste inconnu :

- référence exacte de `IC1` ;
- pinout exact de `IC1` ;
- plage de tension admissible à son entrée ;
- tension nominale réellement appliquée à `CN1-7` dans le véhicule.

Ne pas appliquer 12 V tant que la référence ou au minimum la plage d'entrée admissible de `IC1` n'est pas validée.
