## IC3 — PCA82C250

Pinout constructeur utile :

| Pin IC3 | Fonction |
|---:|---|
| 1 | TXD |
| 2 | GND |
| 3 | VCC — 5 V nominal |
| 4 | RXD |
| 5 | Vref |
| 6 | CANL |
| 7 | CANH |
| 8 | Rs — slope / standby |

Le PCA82C250 est l'interface physique entre le MCU et le bus différentiel CAN.

Plage normale de VCC : `4,5 à 5,5 V`.
Limite absolue de VCC constructeur : `9 V`.

## Alimentation — traçage en cours

### CN1-7 → D1 → condensateur d'entrée C25

Correction de sérigraphie confirmée sur la carte : le gros électrolytique `220 µF / 25 V` est **C25**, et non C2.

Le pad d'alimentation supérieur près de C25 est en continuité avec `CN1-7`. Le pad inférieur est relié à la masse et donc à `CN1-2/8`.

Le traçage montre :

```text
CN1-7 → D1 → rail du gros condensateur C25 220 µF / 25 V
CN1-2/8 → GND → borne négative de C25
```

Mesure en mode diode sur `D1` :

```text
Vf(D1) = 0,551 V
```

Statut : **MEASURED / USER CONFIRMED — 2026-09-04**.

### C3 / PCA82C250 — rail attendu 5 V

Mesures utilisateur :

- `C3` (`47 µF / 16 V`) est sur le rail qui alimente `PCA82C250 pin 3 = VCC` ;
- ce rail est la sortie de l'étage autour de `IC1` ;
- le PCA82C250 attend normalement `4,5 à 5,5 V` sur VCC.

Donc :

```text
C3+ → rail logique attendu ≈ 5 V → PCA82C250 pin 3
```

### Q1 / IC1 — topologie exacte encore à déterminer

Le traçage de `C25+` ne montre pas de liaison directe simple jusqu'à `IC1` : le chemin semble passer par `Q1`, situé sur l'autre face de la carte.

```text
CN1-7 = BCP4 + batterie protégé
  │
  ▼
 D1
  │
  ▼
C25 220 µF / 25 V
  │
  ▼
étage Q1 / IC1 à cartographier
  │             ▲
  │             │
  │        CN1-1 = 34HU
  │        réveil multimédia
  ▼
C3 47 µF / 16 V
  │
  └──► rail attendu ≈ 5 V → PCA82C250 pin 3
```

Le lien électrique exact entre `CN1-1` et `Q1/IC1` n'est pas encore mesuré.

## Premier essai alimentation + wake sur banc — arrêt pour surtension

Essai du `2026-09-04` :

- alimentation appliquée sur les deux pads d'alimentation près de CN1 ;
- source marquée `12 V`, mais mesurée réellement à **16 V** ;
- sans wake, aucun comportement visible ;
- wake ensuite appliqué via une résistance série ;
- le « second condensateur » a alors été mesuré à **11,3 V**.

L'identité exacte de ce « second condensateur » doit être confirmée avant conclusion définitive. S'il s'agit de `C3`, la mesure est **anormale et dangereuse** : `C3` est relié au VCC du PCA82C250, dont la plage normale est `4,5–5,5 V` et la limite absolue VCC est `9 V`.

Conséquence immédiate :

```text
NE PLUS UTILISER CETTE SOURCE 12 V QUI FOURNIT 16 V
```

Le test ne permet pas encore de conclure sur le rôle exact du wake, car la source n'était pas régulée à la tension prévue.

Avant tout nouvel essai :

1. confirmer si le condensateur mesuré à `11,3 V` est bien `C3` ;
2. vérifier que la source utilisée est **DC** et non AC ;
3. utiliser une alimentation DC régulée, idéalement labo ;
4. régler autour de `9 V` avec limitation de courant ;
5. mesurer `C25+`, `C3+` et `PCA82C250 pin 3` avant wake ;
6. appliquer ensuite le wake de façon contrôlée ;
7. remesurer les trois points.

Tant que `C3/PCA82C250 VCC` n'est pas confirmé autour de 5 V, ne pas connecter le CAN et ne pas prolonger les essais sous tension.
