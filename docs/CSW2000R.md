### Corrélation avec nos mesures

La documentation externe explique très bien nos relevés :

```text
CN1-5  = 107W ─┐
               ├── CANH mesuré sur notre PCB
CN1-6  = 34DZ ─┘

CN1-11 = 107X ─┐
               ├── CANL mesuré sur notre PCB
CN1-12 = 34GA ─┘
```

La nomenclature Renault distingue les branches / liaisons du faisceau, tandis que sur notre CSW elles rejoignent effectivement les mêmes nets CAN après entrée sur la carte.

Le pin `CN1-7`, que nous avions déjà tracé vers `D1` puis `C25`, est documenté comme **+ batterie protégé BCP4**. Cela confirme fortement que `CN1-7` est bien l'entrée d'alimentation principale du CSW.

Le pin `CN1-1` est documenté comme **réveil multimédia 34HU**. Il devient donc le candidat prioritaire pour comprendre la commande de mise sous tension de l'étage `Q1 / IC1`.

Les pins `CN1-9` et `CN1-10` sont associés à l'éclairage :

```text
CN1-9  = rhéostat / niveau d'éclairage
CN1-10 = + veilleuses / feux de position
```

Ces deux lignes servent vraisemblablement à la gestion du rétroéclairage de la commande centrale.

## Alimentation — traçage en cours

### CN1-7 → D1 → condensateur d'entrée C25

Correction de sérigraphie confirmée sur la carte : le gros électrolytique `220 µF / 25 V` est **C25**, et non C2.

Le pad d'alimentation supérieur près de C25 est en continuité avec `CN1-7`. Le pad inférieur est relié à la masse et donc à `CN1-2/8`.

Le traçage montre :

```text
CN1-7 → D1 → rail du gros condensateur C25 220 µF / 25 V
CN1-2/8 → GND → borne négative de C25
```

Mesure en mode diode sur `D1` :

```text
Vf(D1) = 0,551 V
```

Statut : **MEASURED / USER CONFIRMED — 2026-09-04**.

La documentation véhicule identifie maintenant `CN1-7 = BCP4 = + batterie protégé`. Le chemin d'alimentation principal est donc considéré **CORROBORATED BY EXTERNAL WIRING DOCUMENTATION**.

### C3 / PCA82C250 — rail logique 5 V confirmé

Mesures utilisateur :

- `C3` (`47 µF / 16 V`) est sur le rail qui alimente `PCA82C250 pin 3 = VCC` ;
- ce rail est la sortie de l'étage autour de `IC1` ;
- le PCA82C250 exige un rail nominal d'environ 5 V.

Donc :

```text
C3+ → rail logique ≈ 5 V → PCA82C250 pin 3
```

Statut : **FUNCTION CONFIRMED — 2026-09-04**.

### Q1 / IC1 — topologie exacte encore à déterminer

Le traçage de `C25+` ne montre pas de liaison directe simple jusqu'à `IC1` : le chemin semble passer par `Q1`, situé sur l'autre face de la carte.

Il est donc prématuré d'affirmer que `IC1` est à lui seul le régulateur 5 V. La formulation de travail devient :

```text
CN1-7 = BCP4 + batterie protégé
  │
  ▼
 D1
  │
  ▼
C25 220 µF / 25 V
  │
  ▼
étage Q1 / IC1 à cartographier
  │             ▲
  │             │
  │        CN1-1 = 34HU
  │        réveil multimédia
  ▼
C3 47 µF / 16 V
  │
  └──► rail ≈ 5 V → PCA82C250 pin 3
```

Le lien électrique exact entre `CN1-1` et `Q1/IC1` n'est **pas encore mesuré**, mais `CN1-1 = réveil multimédia` est désormais documenté extérieurement et doit être tracé en priorité.

Hypothèses possibles pour `Q1` :

- transistor série / pass transistor de la régulation ;
- interrupteur high-side d'alimentation ;
- transistor de commande / enable de l'étage `IC1`.

Statut : **TOPOLOGY TBD — NE PAS SUPPOSER LE RÔLE DE Q1**.
