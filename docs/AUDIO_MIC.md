# Audio & Microphone

## Objectif

Conserver l’amplification et les haut-parleurs Renault autant que possible.

## Piste

Pi → DAC / sortie ligne → AUX Renault → ampli / HP Renault.

## A vérifier

- entrée AUX réellement accessible ;
- niveau ligne ;
- masse ;
- boucle de masse ;
- volume ;
- mute téléphone ;
- comportement CarPlay.

## Micro

Priorité :
1. micro Renault d’origine ;
2. micro automobile externe discret.

Mesurer la nature du micro d’origine avant connexion à une carte son.
