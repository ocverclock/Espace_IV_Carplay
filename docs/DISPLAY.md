# Display

## Décision

- 7"
- non tactile
- IPS
- HDMI privilégié
- façade Renault remplacée par une pièce imprimée 3D.

## Dimensions connues

Ouverture actuelle : environ `130 × 70 mm`.

Cette ouverture n’est pas la cible finale : la nouvelle façade exploitera davantage de surface.

## Critères de choix

- luminosité : objectif 500 nits ou plus si raisonnable ;
- angle de vision ;
- faible reflet ;
- HDMI facilement orientable ;
- faible épaisseur ;
- dimensions du PCB ;
- température de fonctionnement ;
- résolution au moins 1024×600 ;
- contrôle du backlight si possible.

## Validation

Tester avant CAO finale :
- plein jour ;
- nuit ;
- lunettes polarisées si pertinent ;
- démarrage à froid ;
- extinction/allumage rapide.
