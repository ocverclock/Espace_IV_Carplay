# Contributing

Les contributions sont bienvenues, particulièrement :

- brochages Renault vérifiés ;
- photos haute définition des PCB ;
- schémas constructeur ;
- logs CAN correctement documentés ;
- tests sur d’autres Espace IV ;
- corrections de reproductibilité.

## Une affirmation technique doit préciser son statut

- MEASURED
- CONFIRMED
- LIKELY
- HYPOTHESIS

## Pour un relevé CAN

Toujours fournir :
- véhicule / année / équipement ;
- bus et broches ;
- bitrate ;
- action réalisée ;
- timestamp ;
- log brut si possible.

## Pour une modification matérielle

Joindre :
- schéma ;
- références composants ;
- tension ;
- photo du montage ;
- résultat ;
- éventuels effets secondaires.
